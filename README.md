# knowledge-base · 个人经验库（双目录）

沉淀所有项目（AE 脚本 / C4D 插件 / Blender 插件 / Web 项目 / 小程序）的可复用经验。
原则：**写的时候多花 10 秒，找的时候省 10 分钟**。

🔗 **关联管理仓库**：[codebuddy-skills](https://github.com/Simiely/codebuddy-skills)（个人技能仓库）+ [hub-world](https://github.com/Simiely/hub-world)（项目导航/文档快照中心）——本仓管"经验"，那边管"技能/项目"，互相引用。

---

## 仓库结构：一个仓库，两个目录

| 目录 | 定位 | 内容 | 入口 |
|---|---|---|---|
| [`模板库/`](./模板库/) | **骨架（上游）** | 零个人数据：单项目规范 / 条目模板 / 示例条目 / 索引空壳 / 初始化说明 / 归档说明 | [模板库/README.md](./模板库/README.md) |
| [`用户库/`](./用户库/) | **数据（下游）** | 实际使用产生的数据：53 篇解决方案 / 3 篇速查表 / 仓库盘点表 / 最近更新 | [用户库/README.md](./用户库/README.md) |

## 两库关系（铁律）

- **模板库是上游，用户库是下游**
- **数据永不回流模板库**——用户库的经验条目、索引行、盘点表绝不复制进模板库
- 模板库只承载：规范、模板、索引框架、维护规则等骨架；用户库只承载实际内容
- 同仓库迭代：改骨架 → 只动 `模板库/`；沉淀经验 → 只动 `用户库/`，互不干扰、互相可见

## 日常使用

- **踩坑后沉淀** → 进 [`用户库/`](./用户库/)：复制 [`模板库/模板/条目模板与使用说明.md`](./模板库/模板/条目模板与使用说明.md) → 填内容 → 对应索引加行 → 用户库 README 最近更新加行
- **改规范 / 模板** → 只动 [`模板库/`](./模板库/)（骨架改动对所有使用本模板的人生效）
- **开新经验库** → 复制本仓库，或复制 `模板库/` 目录作为新库骨架（详见 [`模板库/初始化说明.md`](./模板库/初始化说明.md)）

## 一套方案，两个层级（单项目 + 多项目）

| 层级 | 管理对象 | 入口 | 核心内容 |
|---|---|---|---|
| **单项目** | 每个仓库内部 | [`模板库/单项目规范/README.md`](./模板库/单项目规范/README.md) | 4 文件分层（README / AGENTS / DEVELOPMENT / CHANGELOG）+ 生长式拆分 |
| **多项目** | 全部仓库的经验沉淀 | [`用户库/README.md`](./用户库/README.md) | 四分类 + 总导航 + 提炼管道 |

**配合流程**：单项目踩坑 → 记录进该仓库的 `DEVELOPMENT.md` / `docs/问题记录/`（与模板同款）→ 项目收尾或季度回顾 → 提炼跨项目通用的内容 → 存入用户库 `解决方案/`、`速查表/` 等。

## 使用建议

本仓库是纯 Markdown，可用 Obsidian 直接打开本目录（模板库 / 用户库同在一个 vault），免费获得全文搜索 + 标签过滤 + 双链图谱；在 GitHub 上浏览亦完全可用。
