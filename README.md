# knowledge-base · 个人经验库

沉淀所有项目（AE 脚本 / C4D 插件 / Blender 插件 / Web 项目 / 小程序）的可复用经验。
原则：**写的时候多花 10 秒，找的时候省 10 分钟**。

## 一套方案，两个层级（单项目 + 多项目）

| 层级 | 管理对象 | 入口 | 核心内容 |
|---|---|---|---|
| **单项目** | 每个仓库内部 | [`单项目规范/README.md`](./单项目规范/README.md) | 4 文件分层（README / AGENTS / DEVELOPMENT / CHANGELOG）+ 生长式拆分 |
| **多项目** | 全部仓库的经验沉淀 | **本文件（README）** | 四分类 + 总导航 + 提炼管道 |

**配合流程**：单项目踩坑 → 记录进该仓库的 `DEVELOPMENT.md` / `docs/问题记录/`（与本文档同模板）→ 项目收尾或季度回顾 → 提炼跨项目通用的内容 → 存入本库 `解决方案/`、`速查表/` 等。

## 目录结构

```
knowledge-base/
├── README.md            # 本文件：总导航
├── 单项目规范/          # 单项目（单仓库）文档规范 ← 单项目层级
├── 解决方案/            # 踩坑与解决（一坑一篇）
├── 复用模式/            # 跨项目复用的模式 / 工作流
├── 速查表/              # 速查清单（拿来就用）
├── 模板/                # 脚手架 / 配置模板
└── 归档/                # 过时条目归档
```

## 分类边界（放什么 / 不放什么）

| 目录 | 放什么 | 不放什么 |
|---|---|---|
| `解决方案/` | 一个问题一篇文章：问题 → 根因 → 解决 → 预防 | 通用可复用代码 → 复用模式/ |
| `复用模式/` | 跨项目通用的模式 / 工作流 | 一次性问题 → 解决方案/ |
| `速查表/` | 速查：API 清单、语法限制、常用命令 | 完整教程 / 长篇讲解 |
| `模板/` | 可直接复制的脚手架、配置模板 | 需要解释说明的内容 → 解决方案/ |

## 场景速查（我在做什么 → 看这里）

- 写 AE 脚本（ES3 语法限制 / JSON polyfill） → `速查表/ES3语法限制速查.md`
- 写 AE 脚本（ScriptUI 布局问题） → `解决方案/ScriptUI布局两坑.md`
- AE 属性取不到 / matchName 不匹配 → `解决方案/AE2026中文版matchName兼容.md`
- 做文字动画器（逐字 / 波浪 / 散落） → `解决方案/AERangeSelector只用Percent模式.md`
- 想规范单个仓库的文档 → `单项目规范/README.md`
- 忘记某条经验在哪 → Obsidian 打开本目录全文搜索

## 条目模板（怎么用）

新增经验条目的标准流程，**复制模板文档，不用记规则**：

1. 复制 `模板/条目模板与使用说明.md` → 改为中文命名（`领域-主题`，如 `AE2026中文版matchName兼容.md`）
2. 放到对应分类目录（`解决方案/` `复用模式/` `速查表/` `模板/`，边界见上表）
3. 按模板内的字段说明和正文指引填空（frontmatter + TL;DR + 问题/根因/解决/预防）
4. 更新对应 `索引.md` 加一行 + 本文件「最近更新」加一行

- **模板文档**：`模板/条目模板与使用说明.md`（含字段说明表、每节写什么、空白模板）
- **完整示例**：`解决方案/AE2026中文版matchName兼容.md`（首批条目均提炼自 AE-Lyrics-Animator，见该仓库 DEVELOPMENT.md）

## 维护规则

- **新增一条**：① 套模板写一个 md 文件 → ② 对应 `索引.md` 加一行 + 本文件「最近更新」加一行
- **命名**：中文命名，`领域-主题`（中文为主 + 必要英文缩写，不带空格），如 `AE2026中文版matchName兼容.md`（文件名即关键词）
- **归档**：过时 / 不再使用的条目移入 `归档/`，活跃区保持简洁
- **提炼节奏**：项目收尾或解决问题后顺手写，不搞额外复盘仪式
