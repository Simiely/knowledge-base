# 经验条目模板 · 使用说明

> 新增任何经验条目时，**复制本文件** → 改名 → 按下面指引填空。
> 本文件同时是「空白模板」和「使用说明书」，不需要背规则。
>
> ⚠️ **隐私红线**：本知识库公开可见，禁止写入 token / 密码 / 邮箱 / 本地路径等敏感信息（详见根 README 维护规则）。

## 一、复制与放置

1. 复制本文件，改为**中文命名**：`领域-主题`（中文为主、保留必要英文缩写、不带空格）
   - 例：`C4D2026移除的PythonSDK接口.md`、`AEScriptUI宽度失控.md`
2. 放到对应分类目录（见下表），文件名即关键词，方便搜索。

## 二、放哪个分类

| 我在做什么 | 放哪里 |
|---|---|
| 解决了一个具体的坑 / 报错 | `解决方案/` |
| 提炼出通用做法 / 固定流程 | `复用模式/` |
| 常用清单（语法限制、API、命令） | `速查表/` |
| 可直接复制的结构 / 配置 | `模板/` |
| 不确定？先放 `解决方案/`，内容多了再挪 | — |

## 三、Frontmatter 字段怎么填

| 字段 | 必填 | 填什么 |
|---|---|---|
| `tags` | 是 | 领域标签（`ae` / `c4d` / `blender` / `web` / `miniprogram`）+ 关键词，逗号分隔 |
| `date` | 是 | 创建日期 `YYYY-MM-DD` |
| `status` | 是 | `stable` / `draft`（没写完）/ `outdated`（已过时，准备归档） |
| `related` | 否 | 关联条目路径，如 `[解决方案/C4D2026移除的PythonSDK接口.md]`，建立双链 |
| `source` | 否 | **来源链接**：提炼自哪个仓库的 GitHub 位置（blob 链接），如 `https://github.com/Simiely/AE-Lyrics-Animator/blob/main/DEVELOPMENT.md`；正文末尾再加「## 来源」小节标注对应章节 |

## 四、正文怎么写

- **TL;DR**：一句话说清结论 —— 这是快速提取的抓手，必须写
- **问题 / 根因 / 解决 / 预防**：每节 1~5 句，说人话，别写长篇
- **解决**里放可复制的代码 / 命令；**预防**里放"下次怎么避免"（防坑经验最值钱）
- 完整参考：`解决方案/C4D2026移除的PythonSDK接口.md` 等四个示例条目

## 五、写完后

1. 对应分类的 `索引.md` 加一行（条目 | 摘要 | 标签 | 日期）
2. 根目录 `README.md` 的「最近更新」加一行
3. 完成。日常维护只有这两步。
