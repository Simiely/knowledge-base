# v2.0.0 迁移说明

从 v1（四件套，无机器层）升级到 v2。

## 影响范围

- 需要新增 `tools/repo-kit/`、`schema/`、`requirements.txt`、`.github/workflows/repo-check.yml`
- 所有纳入扫描的 Markdown 需要标准 frontmatter
- `AGENTS.md` 建议改为模板生成，基线行写“日期 + commit”
- `schema/kit.lock.json` 会写入 `spec_version: 2.0.0`

## 步骤

1. 用知识库的 `模板库/repo-kit/tools/update-repo-kit.ps1 -Source <知识库>/模板库/repo-kit -Profile <profile>` 安装 kit
2. 按 `REPO_STANDARD.md` 补齐 frontmatter 与目录
3. 运行三项检查：

```powershell
python tools/repo-kit/check_repo.py --root .
python tools/repo-kit/generate.py --root . --check
pwsh tools/update-repo-kit.ps1 -Check
```

4. 推送后确认 `repo-check` CI 通过
5. 回填 AGENTS 基线 hash 与 `用户库/仓库盘点表.md` 的规范版本、基线列

## 验收

- 三项检查 PASS
- `kit.lock.json` 中 `spec_version` 等于 `2.0.0`
- 盘点表可检索到该仓库且版本一致
