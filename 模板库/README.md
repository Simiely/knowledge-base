# 模板库 · 个人经验库骨架

> 一套「拿来即用」的个人经验库骨架：**零个人数据**。
> 沉淀所有项目（AE 脚本 / C4D 插件 / Blender 插件 / Web 项目 / 小程序）的可复用经验。
> 原则：**写的时候多花 10 秒，找的时候省 10 分钟**。

🔗 **怎么用**：本目录是 `knowledge-base` 仓库的**骨架（上游）**，与 [`../用户库/`](../用户库/README.md)（数据）同仓库、分开迭代。开新经验库 → 复制本目录或整个仓库 → 按 [`初始化说明.md`](./初始化说明.md) 操作。

---

## 一套方案，两个层级（单项目 + 多项目）

| 层级 | 管理对象 | 入口 | 核心内容 |
|---|---|---|---|
| **单项目** | 每个仓库内部 | [`单项目规范/README.md`](./单项目规范/README.md) | 4 文件分层（README / AGENTS / DEVELOPMENT / CHANGELOG）+ 生长式拆分 |
| **多项目** | 全部仓库的经验沉淀 | [`../用户库/README.md`](../用户库/README.md) | 四分类 + 总导航 + 提炼管道 |

**配合流程**：单项目踩坑 → 记录进该仓库的 `DEVELOPMENT.md` / `docs/问题记录/`（与本文档同模板）→ 项目收尾或季度回顾 → 提炼跨项目通用的内容 → 存入用户库 `解决方案/`、`速查表/` 等。

## 条目模板（怎么用）

新增经验条目的标准流程，**复制模板文档，不用记规则**：

1. 复制 `模板/条目模板与使用说明.md` → 改为中文命名（`领域-主题`，如 `AE2026中文版matchName兼容.md`）
2. 放到用户库对应分类目录（`解决方案/` `复用模式/` `速查表/`，边界见上表）
3. 按模板内的字段说明和正文指引填空（frontmatter + TL;DR + 问题/根因/解决/预防）
4. 更新用户库对应 `索引.md` 加一行 + 用户库 README「最近更新」加一行

- **模板文档**：`模板/条目模板与使用说明.md`（含字段说明表、每节写什么、空白模板）
- **完整示例**：`模板/示例条目-工具类.md`（中性示例，**开新库后可直接删除**）

## 维护规则

- **本目录只放骨架**：规范、模板、索引空壳、维护规则。**任何实际经验数据都放用户库**
- **命名**：中文命名，`领域-主题`（中文为主 + 必要英文缩写，不带空格），文件名即关键词
- **归档**：过时 / 不再使用的模板或骨架说明移入 `归档/`，活跃区保持简洁
- **提炼节奏**：项目收尾或解决问题后顺手写，不搞额外复盘仪式
- **隐私红线（公开仓库）**：禁止收录任何敏感数据——凭据（token / 密码 / API Key）、个人信息（邮箱 / 手机 / 住址）、本地绝对路径、未公开的项目细节。发现已收录 → 立即清理并提交说明

## 模板库 ↔ 用户库（同仓库双目录怎么配合）

| 实体 | 是什么 | 谁维护 |
|---|---|---|
| **本目录**（`模板库/`） | 骨架：规范、模板、索引空壳、维护规则。**零个人数据** | 想改骨架时 |
| **用户库**（`../用户库/`） | 数据：实际经验条目、索引行、盘点表、最近更新 | 每次踩坑后 |

- **同仓库迭代**：改骨架 → 只动 `模板库/`；沉淀经验 → 只动 `用户库/`。互相可见、互不干扰，一个 PR 即可同时管理
- **开新库**：复制本目录作为新库骨架（详见 [`初始化说明.md`](./初始化说明.md)）
- **原则**：模板库是「上游」，用户库是「下游」；**数据永不回流模板库**
