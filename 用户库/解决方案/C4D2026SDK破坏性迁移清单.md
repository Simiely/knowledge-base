# C4D 2026 SDK 破坏性迁移清单

**TL;DR**：C4D 2025 → 2026 有大量破坏性 API 变更：**ListView 全套、`GePopupMenu`、`gui.Question`、`ScrollGroupEnd` 被移除**；`AddStaticText(border=)`/`AddComboBox(cols=)` 等 kwargs 变 positional-only；`typeflags=` 改 `type=`；`CreateLayout` 签名变化；低频常量被移除。迁移前先查 SDK 文档。

## 已确认的破坏性变更

| 变更 | 替代方案 |
|---|---|
| `AddListView` 及 9 个配套方法移除 | ScrollGroup + 动态控件模拟（见 解决方案/C4D动态列表控件方案.md） |
| `ScrollGroupEnd` 移除 | 用 `GroupEnd()` 收尾 |
| `c4d.gui.GePopupMenu` 移除 | 少量预设用独立按钮行；弹窗用 `AddPopupButton` |
| `gui.Question("...")` 移除 | `gui.QuestionDialog("...")`（接口兼容） |
| `storage.LoadDialog(typeflags=)` | 参数改名 `type=` |
| `CreateLayout(self, parent_dlg)` | 2026 只传 self，用 `def CreateLayout(self, parent_dlg=None)` 兼容 |
| 低频常量移除（如 `CUSTOMGUI_COLORFIELD`） | `_c(name, fallback)` 兼容层：`getattr(c4d, name, fallback)` |
| `AddStaticText(border=)` / `AddComboBox(cols=)` | kwargs 变 **positional-only**，报 `'xxx' is an invalid keyword argument` 就改位置传参（border→第6位，cols→第3位） |

## 预防

- **先查 Python SDK 文档再写代码**，别沿用 C++ 习惯或旧版记忆
- 遇到 `'xxx' is an invalid keyword argument` → 把该参数改位置传参（`flags=`/`name=`/`initw=`/`title=`/`rows=` 等主参数不受影响，只有末位边缘参数受影响）
- 常量一律 `_c()` 包裹；**UI 相关常量（单位/自定义 GUI/边框）是高危区，数据类型常量是稳定区**
- 已确认 C4D 2026 仍然可用的 GeDialog 方法（AddButton/AddStaticText/AddComboBox/AddChild/AddPopupButton/GroupBegin/GroupEnd/ScrollGroupBegin/SetString/GetString/LayoutChanged/LayoutFlushGroup 等），见 c4d-userdata-manager DEVELOPMENT.md 快速参考
