# 桌面程序安全汉化方法论

**TL;DR**：汉化桌面程序（Qt 等）先判断界面文字来源：① exe 二进制硬编码（改二进制高风险）；② Qt 官方翻译机制 `.qm/.ts`（无）；③ **外部 UI 定义文件（XML/.ui）——最安全路径，只改文件不碰 exe**。翻译只动"显示属性"，绝不翻命令/内部标识。

## 问题
需求方要求汉化 TopoGun 3（Qt5 桌面应用）且不影响功能。第一步必须判断文字来源，否则误改 exe 可能崩溃。

## 判断流程
1. **提取 exe 可打印字符串**：看界面文字是否硬编码在二进制里
2. **检查 Qt 翻译机制**：`.qm` / `.ts` 文件存在与否
3. **找外部 UI 定义**：`%APPDATA%` 下 `menubar/` `ui/` `tools/` `piemenu.xml` 等，含可见英文 → **文字来自外部文件，只改文件即可**

## 安全汉化原则
- **只翻译"显示属性"**：XML `text=` / `buttonText=` / `toolTip=`；`.ui` 的 `<property name="text|title|windowTitle|toolTip|whatsThis|statusTip|placeholderText">`
- **绝不翻译**命令/内部标识：`name=` `target=` `icon=` `context=` `key=` `toolName=` `value=`——程序用它们定位功能，翻译会破坏菜单/工具栏
- 不改二进制、不改文件结构、不改编码

## 预防
- 汉化前先定位文字来源（二进制 vs 外部文件），选最安全路径
- 只翻显示属性是铁律，标识符一个都不能动
- 改完用原程序完整跑一遍菜单/工具栏验证
