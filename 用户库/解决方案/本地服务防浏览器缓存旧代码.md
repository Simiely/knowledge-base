# 本地服务防浏览器缓存旧代码

**TL;DR**：本地 GUI/预览服务对页面和 JS 的响应若不设缓存控制，浏览器会缓存旧代码，导致"代码已修但界面表现依旧"。

## 问题
修完 bug、无头浏览器实测正常，但用户浏览器上仍复现旧行为（如按钮一直转圈），与代码不符。

## 根因
浏览器 HTTP 缓存把旧 `wb-gui.js` 等资源缓存在本地，新请求直接命中缓存，加载的是修复前的代码。

## 解决
本地服务对 `/` 与静态资源（`/wb-gui.js` 等）响应头加：

```
Cache-Control: no-store
```

浏览器强制每次重新获取，永远拿最新代码。

## 预防
- 任何"改代码 → 前端页面"的本地服务都要考虑缓存，静态资源一律 `no-store`（本地工具没有缓存收益）
- 排查"改了没效果"类问题，先排除浏览器缓存（强刷 / 无痕），再看 Console 报错
