| 层级 | 管理对象 | 入口 | 核心内容 |
|---|---|---|---|
| **单项目** | 每个仓库内部 | [`../模板库/单项目规范/README.md`](../模板库/单项目规范/README.md) | 4 文件分层（README / AGENTS / DEVELOPMENT / CHANGELOG）+ 生长式拆分 |

## 仓库盘点（断点索引）

**是什么**：[`仓库盘点表.md`](./仓库盘点表.md) 记录**所有仓库**的文档规范状态——哪些已按单项目规范重写、重写日期、基线 commit，以及未完成/未处理的仓库清单。

**为什么**：仓库重写完成后必须留下基线标记（日期 + commit hash）。否则以后更新了没人记得"重写到哪"，可能从头重写。基线 hash 支持 `git diff <基线hash>` 精确对比"上次重写后改了什么"——**断点续传**。

**怎么用**：
- **查**：要更新某仓库前，先看盘点表拿到它的基线 commit → `git log --oneline <基线hash>..HEAD` 看增量
- **维护**：更新仓库后四步回填——① 该仓库 CHANGELOG 追加版本 → ② AGENTS 基线行更新 → ③ 本表回填新 hash → ④ 推送

> 规则详见 [`../模板库/单项目规范/README.md`](../模板库/单项目规范/README.md) 第九节「文档基线」；每条仓库的基线行在各自 AGENTS.md 顶部。

## 条目模板（怎么用）

新增经验条目的标准流程，**复制模板文档，不用记规则**：

1. 复制 [`../模板库/模板/条目模板与使用说明.md`](../模板库/模板/条目模板与使用说明.md) → 改为中文命名（`领域-主题`，如 `AE2026中文版matchName兼容.md`）
2. 放到对应分类目录（`解决方案/` `复用模式/` `速查表/`，边界见上表）
3. 按模板内的字段说明和正文指引填空（frontmatter + TL;DR + 问题/根因/解决/预防）
4. 更新对应 `索引.md` 加一行 + 本文件「最近更新」加一行

- **模板文档**：[`../模板库/模板/条目模板与使用说明.md`](../模板库/模板/条目模板与使用说明.md)（含字段说明表、每节写什么、空白模板）
- **完整示例**：`解决方案/AE2026中文版matchName兼容.md`（首批条目均提炼自 AE-Lyrics-Animator，见该仓库 DEVELOPMENT.md）

## 维护规则

- **新增一条**：① 套模板写一个 md 文件 → ② 对应 `索引.md` 加一行 + 本文件「最近更新」加一行
- **命名**：中文命名，`领域-主题`（中文为主 + 必要英文缩写，不带空格），如 `AE2026中文版matchName兼容.md`（文件名即关键词）
- **归档**：过时 / 不再使用的条目移入 `归档/`，活跃区保持简洁
- **提炼节奏**：项目收尾或解决问题后顺手写，不搞额外复盘仪式
- **隐私红线（公开仓库）**：禁止收录任何敏感数据——凭据（token / 密码 / API Key）、个人信息（邮箱 / 手机 / 住址）、本地绝对路径、未公开的项目细节。发现已收录 → 立即清理并提交说明
- **断点续传**：更新某仓库后，① 该仓库 CHANGELOG 追加版本 → ② AGENTS 基线行更新（日期+hash）→ ③ `仓库盘点表.md` 回填新 hash → ④ 推送（规则见 [`../模板库/单项目规范/README.md`](../模板库/单项目规范/README.md) 第九节）
- **骨架迭代**：规范 / 模板 / 索引框架由 [`../模板库/`](../模板库/README.md) 统一维护，本目录只放数据；**数据永不回流模板库**。模板库改骨架后，本目录无需同步（同仓库，引用即最新）
