# 微信小程序域名与网络硬约束

**TL;DR**：**小程序只能跟「你自己备案的域名」通信**——这是所有外部数据接入的总约束。HTTPS 强制 + 域名白名单 + 备案主体与小程序一致 + 无 DOM + 主包 ≤2MB。**体验版照常校验域名**（不是免校验），唯一免白名单连局域网的是「真机调试」（但不能分享）。

## 硬约束清单

| 约束 | 说明 |
|---|---|
| HTTPS 强制 | 所有网络请求必须 HTTPS + 有效证书 |
| 域名白名单 | 请求域名必须在公众平台「服务器域名」配置（request/downloadFile/uploadFile 分开） |
| 备案主体一致 | 域名须国内备案，且**备案主体与小程序主体一致**（个人↔个人，企业↔企业） |
| 无 DOM | 不能 innerHTML/document，HTML 需解析库（towxml/marked）渲染 |
| 包体限制 | 主包 ≤ 2MB，大资源远端按需拉或子包 |

## 版本与白名单差异（常见误解）

| 环境 | 域名白名单 | 连局域网 | 能否分享 |
|---|---|---|---|
| 模拟器 | 勾"不校验"后免 | ✅ | 仅自己 |
| 真机调试 | 勾"不校验"后免 | ✅ | ❌ 不能分享 |
| **体验版** | **❌ 照常校验** | ❌ | ✅ 加体验者微信号 |
| 正式版 | ❌ 照常校验 | ❌ | ✅ 所有人 |

> 开发版预览码能长期点开是因为代码包缓存在手机本地，只要发 `wx.request` 白名单照样拦。**体验版 ≠ 免域名校验**。

## 外部数据源接入可行性

| 数据源 | 可行性 | 原因 |
|---|---|---|
| OSS/COS（自有备案域名） | ✅ | 直链 HTTPS 配白名单 |
| 自建服务器 / 云函数 | ✅ | 最灵活，可鉴权/转换 |
| **腾讯文档 + 云开发中转** | ✅ | 走微信云开发通道免白名单，**规避备案门槛** |
| 个人网盘 | ❌ | OAuth 网页跳转，小程序无浏览器环境 |
| 第三方穿透域名 | ❌ | 备案主体不符，配不进白名单 |
| 局域网 NAS IP | ❌（仅真机调试） | 非 HTTPS、IP 不能配白名单 |

## 预防

- 接数据源先问一句：「是不是我自己备案的域名」；不想备案 → 优先云开发（免白名单）
- web-view 仅**企业主体**可用（个人主体无权限），且是独立的「业务域名」白名单
- 订阅消息必须先用户主动授权（一次性订阅 7 天内一条；长期订阅仅特定类目）
